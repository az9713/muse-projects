3. Design decisions

#9 folding: first attempt used a numeric-segment regex, but the traffic also held /products/abc and /orders/9999. Replaced with parent-group folding — a non-root parent with several distinct children is an id slot. Root-level paths never fold.

#13 census roots: entry-module functions (app) count as reachable roots; anything else unimported is dead. Fixtures keep planted dead code so the tool stays testable after src/ went clean.

#14 honesty: wrote the naive splitter first, captured the red fuzz run in findings.log, then fixed — same red-green discipline as #6.

#16 rehearsal: the log asserts byte-identical user rows across a v3 excursion, not just version numbers.

4. What went wrong, and the fixes

F-1 (#8): test_create_normalizes_tags — AssertionError. The typed rewrite dropped tag normalization the test required. Fix: normalize (strip/lower/dedupe) inside new_task, reject empties.

F-2 (#8): mypy ... Found 1 error in 1 file — int(row["id"]) on an object value. Fix: int(str(row["id"])) plus isinstance narrowing for tags; zero type: ignore comments in the final code.

F-3 (#9): inferred 8 endpoints, expected 5 — the fold regex was double-escaped (r"/\\d+") so nothing folded. Fixed regex, then replaced the approach with parent-group folding (see §3).

F-4 (#9): 'GET /orders/1001' not found in {...}. The test was right and the fixture incomplete — added the missing sample instead of weakening the test.

F-5 (#10): my own no-v1-imports test only inspected the last file (loop variable overwrite). Rewrote to check all three call sites by path.

F-6 (#11): FileNotFoundError: tests/logs/access.log — tests resolved paths beside themselves instead of the project root. Fixed with a ROOT constant.

F-7 (#13): 'HELLO, ANN' != 'HELLO, ANN' — test assumed stripping the implementation never did. Fixed the test input, not the code.

F-8 (#16): rehearsal seeded rows before up(v1) created the table. Rewrote the script with strict create-then-seed order.

F-R1 (process): heal.sh reported FAIL regen #5 — an old ruff auto-fix had reformatted generated out/client.py without updating the generator. Fixed the generator template (import order) so regen is byte-clean again. Rule learned: generated files are fixed at the generator, never in the output.
