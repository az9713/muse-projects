#1 MIGRATION RUNNER

Before/after suites for mechanical migrations

Python unittest → pytest and JS CommonJS → ESM: every file touched, behavior preserved, verified by a parity script.

cd project-1-migration/python-sample
uv venv && source .venv/bin/activate && uv pip install pytest
python -m unittest discover -s tests -p 'test_legacy_unittest.py' -t .  # 12 pass
python -m pytest tests/test_migrated_pytest.py -v                       # 15 pass
python3 check_parity.py                                                 # 10 checks

cd ../js-sample
node test/test-legacy.cjs                   # 12 asserts
node --test test/test-migrated.test.mjs     # 13 pass
#2 COLD-START FEATURE

Tags across a layered task tracker

Store → service → CLI + docs. The agent was handed only TASK.md plus a directory listing. Try the feature:

cd project-2-coldstart/python
uv venv && source .venv/bin/activate && uv pip install pytest
python -m pytest tests/ -q                  # 10 passed
python -m tasks.cli add "Write report" --tags work,urgent
python -m tasks.cli list --tag work

cd ../js
node --test test/tags.test.mjs              # 10 passed
node src/cli.mjs add "Write report" --tags=work,urgent
node src/cli.mjs list --tag=work

#4 POLYGLOT CLI

One CLI scaffolds three languages

#7 SELF-HEALING CI

Whole repo green in one command

heal.sh runs every pytest suite, every node suite, the #5 regen drift check, and ruff lint with auto-fix. Mirrored per-job by .github/workflows/ci.yml, plus a Docker build for the Python suites.
