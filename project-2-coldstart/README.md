# #2 Cold-start feature (both minimal)

Two unfamiliar layered apps; each agent run starts from `TASK.md` + a
directory listing only and must implement tags across store, service,
CLI, docs, and tests.

- `python/` — `tasks/` package + `docs/API.md`. Env in `python/.venv`.
- `js/` — `src/*.mjs` + `docs/API.md`. Stdlib only.
